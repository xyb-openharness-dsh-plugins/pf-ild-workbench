## 四、刻意不同（≥3 条，理由 + audit 风险）

1. **不设分期页**：PF-ILD 无 TNM/FIGO 分期概念，分期档案页会空转。理由：R2 形态。
2. **治疗线改为「用药与耐受记录」**：不设化疗线/放疗线，改为抗纤维化药 + 激素 + 免疫抑制剂的剂量变更与耐受事件记录。理由：患者最关心「什么时候减的药、为什么」。
3. **事件类型不同**：肿瘤仓是治疗事件，本仓是**急性加重住院事件**（自然病程事件）。理由：急性加重是患者最需要知道"前后怎么变"的锚点。
4. **新增「移植评估信息自检」**：肿瘤仓无移植。理由：肺移植是 PF-ILD 的关键窗口决策。
5. **趋势图是「功能趋势」而非「指标趋势」**：肺功能 FVC%pred/DLCO%pred 是核心，量表（mMRC/King-ILD）分类不进趋势折线。

## 五、26 号口径里对 R2 形态不适用项（逐条）

**明确不适用 5 条**：

| 口径 | 不适用原因 |
| --- | --- |
| 分期/分型档案（TNM / FIGO / BI-RADS） | R2 慢性病无分期体系 |
| 肿瘤标志物趋势（CA 系列 / SCC-Ag） | 无对应标志物；26 号明写标志物不做分级 |
| 手术/放化疗治疗路径线 | 本病种无手术放化疗主线 |
| CTCAE v5.0 毒性分级（指标分级层） | 抗肿瘤毒性分级，PF-ILD 用药无对应阈值 → 改为原样文本不分级 |
| 预后/复发/进展风险分层 | 不做判读（医生任务），26 号与乳腺 SPEC 均明写不做 |

**部分适用 / 条件适用 4 条**：术后恢复与上肢淋巴水肿（无手术）、家属早筛与遗传咨询（无家族传播维度）、癌种专属营养（肌少症三联/限盐/酶补充，体重部分仍可用）、临床试验线索（无真实登记库不设入口）。

保留适用：看板、数值趋势、症状记录、体重、心理、复诊随访、资料导出、一图秀时间轴、指南出处与节奏层。
