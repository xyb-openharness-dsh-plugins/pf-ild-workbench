## 四、刻意不同（≥3 条，理由 + audit 风险）

1. **不设分期页**：PF-ILD 无 TNM/FIGO 分期概念，分期档案页会空转。理由：R2 形态。
2. **治疗线改为「用药与耐受记录」**：不设化疗线/放疗线，改为抗纤维化药 + 激素 + 免疫抑制剂的剂量变更与耐受事件记录。理由：患者最关心「什么时候减的药、为什么」。
3. **事件类型不同**：肿瘤仓是治疗事件，本仓是**急性加重住院事件**（自然病程事件）。理由：急性加重是患者最需要知道"前后怎么变"的锚点。
4. **新增「移植评估信息自检」**：肿瘤仓无移植。理由：肺移植是 PF-ILD 的关键窗口决策。
5. **趋势图是「功能趋势」而非「指标趋势」**：肺功能 FVC%pred/DLCO%pred 是核心，量表（mMRC/King-ILD）分类不进趋势折线。

## 五、26 号口径里对 R2 形态不适用项（逐条）

**明确不适用 5 条**：

| 口径 | 不适用原因 |
| --- | --- |
| 分期/分型档案（TNM / FIGO / BI-RADS） | R2 慢性病无分期体系 |
| 肿瘤标志物趋势（CA 系列 / SCC-Ag） | 无对应标志物；26 号明写标志物不做分级 |
| 手术/放化疗治疗路径线 | 本病种无手术放化疗主线 |
| CTCAE v5.0 毒性分级（指标分级层） | 抗肿瘤毒性分级，PF-ILD 用药无对应阈值 → 改为原样文本不分级 |
| 预后/复发/进展风险分层 | 不做判读（医生任务），26 号与乳腺 SPEC 均明写不做 |

**部分适用 / 条件适用 4 条**：术后恢复与上肢淋巴水肿（无手术）、家属早筛与遗传咨询（无家族传播维度）、癌种专属营养（肌少症三联/限盐/酶补充，体重部分仍可用）、临床试验线索（无真实登记库不设入口）。

保留适用：看板、数值趋势、症状记录、体重、心理、复诊随访、资料导出、一图秀时间轴、指南出处与节奏层。

## 六、26 号 L1–L10 逐条答问（上 / 不上 / 为什么——沉默漏掉是最常见失误）

> 依据 26 号 §「每一条都要显式回答"上 / 不上 / 为什么"」。本仓为 R2 非肿瘤慢性病形态，答问按此形态。

| 线 | 26 号定义 | 本仓决定 | 理由与落点 |
| --- | --- | --- | --- |
| L1 看板/首页 | 我现在整体什么情况？ | **上** | SPEC §四 看板；R2 形态看板以「接下来/今天/趋势摘要」三段组织，不做肿瘤式治疗线总览 |
| L2 疾病本体线 | 我这个病到底处在哪一步？ | **上（换形）** | 无分期体系 → 由「诊断追溯（起病→确诊时间线）」承接本体；**不设分期页**（26 号 §「写下来才算决定过」） |
| L3 治疗与决策线 | 我做过什么、接下来还有什么路？ | **上（换形）** | 无手术/放化疗主线 → 由「用药与耐受记录」承接；移植评估作为决策节点单列（L3 的决策面） |
| L4 指标分析线 | 这个数高了/低了要紧吗？比上次呢？ | **上（收窄）** | 由「肺功能趋势」承接；**CTCAE 阈值表不适用**（无抗肿瘤毒性分级）→ 改绝对值/相邻差值对照，无判读 |
| L5 安全与症状线 | 这个不舒服是不是治疗带来的？ | **上（换形）** | 由「急性加重事件 + 氧状态快记」承接；事件是**自然病程事件**而非治疗事件 |
| L6 营养与体重线 | 我吃得下吗？掉了的体重要紧吗？ | **待定（G1 缺口）** | 体重可进趋势；**进食记录无落点**。用户研究 G6：中国 PF-ILD 营养需求无直接证据（二手诉求有）→ 方案 A 独立线 / 方案 B 并入 S02，G1 拍板（HVT-REVIEW §4 G1） |
| L7 心理与家庭线 | 我很怕，能跟谁说？家里人要做什么？ | **上（并入）** | 用户研究 D6（强证据：焦虑抑郁高发）→ 当下感受记录 + 情绪困扰进复诊问题清单；**不设独立一级线**（R2 形态与 FSHD 一致）；**无家属早筛**（无遗传传播维度） |
| L8 复诊与随访线 | 下次什么时候、带什么去？ | **上** | SPEC §四「复诊待办与问题清单」；含肺功能 3 个月节奏 + 移植评估信息自检 |
| L9 资料与导出线 | 我能不能整理好拿去给医生看？ | **上** | SPEC §四「报告与资料整理」；私密内容默认不导出（心理/情绪记录） |
| L10 试验与线索线 | 还有没有我能参加的研究？ | **上（条件）** | M4 接 unified-trial-mcp 在线四通道；**离线语料无覆盖**（如实声明）；无真实登记库则不设入口（26 号原文） |

**贯穿机制三条**：① 指标分级层——**CTCAE 不适用**，改 26 号「只对有绝对阈值的项做对照」（METRIC-GRADING）；② 一图秀/时间轴层——**上**，多指标 + 事件同轴、独立归一化、单点不连线；③ 指南出处与节奏层——**上**，只做「出处 + 节奏 + 并列口径」（25 号四层刻度尺）。
