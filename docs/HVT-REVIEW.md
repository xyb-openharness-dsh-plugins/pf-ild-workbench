## 4. 差异评价与补丁

### G1 · S07 营养线未定线（G 缺口，C=2，P=6）

- **现象**：患者核心场景「气促吃不下、体重在掉」在 SCENARIOS 有场景（V=2 S=2 F=2），但 SPEC §四 9 个一级功能线与 SCHEMA 专属 7 表均无营养模块——体重虽可作为 metric_definition 记录，但「进食量 / 症状 / 食谱负担」这类 R2 形态的营养记录没有落点。
- **证据**：`grep -rnE "营养|进食" docs/*.md` → SCENARIOS 1 处、METRIC-GRADING 2 处；`docs/SCHEMA.md` 表清单无营养表；`docs/SPEC.md` §四 无营养功能线。
- **影响**：照现有文档实现，S07 场景会退化成"体重数字进趋势图"，丢失「气促→进食减少」这条 PF-ILD 特有因果链的日常记录；26 号 L6（营养与体重线）会被机械判"缺线"。
- **处置（补丁，待用户在 G1 拍板）**：二选一——
  - **方案 A（推荐）**：新增一级线「营养与日常功能」，含进食量记录 + 体重趋势 + mMRC 活动耐量对照；SCHEMA 加 `nutrition_log` 表（26 号 L6 体重部分 + R2 呼吸功能形态）。
  - **方案 B**：不设独立一级线，S07 并入「氧状态与日常快记」的二级页（进食量作为快记的可选维度）；理由：R2 慢性病营养问题占比低于肿瘤恶病质，避免与 S02 重叠。
  - 无论选哪个，都要在 DIFF-MATRIX §一 显式回答 26 号 L6「上 / 不上 / 为什么」。
