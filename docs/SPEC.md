## 一、设计者与研究/场景依据

- 角色：患者本人为主 + 家属辅助（2026-10-25 用户确认）。设计者代表患者记录者，而非医生流程执行者。
- **医学口径**：本项目不做诊断、不做处置建议。PF-ILD/PPF 判定、急性加重诊断、移植适应证评估均为**医生任务**，本工作台只做「信息准备 + 并列口径展示 + 记录」。
- 场景取舍原则：每条功能线挂一句患者视角需要；无一手证据的需求一律标 ⏳。
- 证据来源：`research/USER-RESEARCH-2026-10-25.md`（0 访谈全二手；8 个患者信息维度 D1–D8 + 12 条「医生任务≠患者需要」一票否决清单）、`research/FAMILY-COMPARISON-2026-10-25.md`（一级重名率实测）。

## 二、问题、用户与最小闭环

输入：纸质/电子报告 + 日常自录（肺功能、氧饱和度、症状、用药）。
动作：核对入档 → 看趋势 → 复诊待办。
输出：来源可追溯的个人病程档案 + 可勾选复诊问题清单。
失败恢复：数据根选择错误、凭据缺失、外部源不可用 → 本地降级 + 明确提示，不静默失败。
成功标准：患者能回答「我上一次之后到现在是稳还是变」以及「这次复诊要问什么」。
