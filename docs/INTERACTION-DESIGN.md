## 二、CRUD 双通道矩阵（每个可写实体一行）

| 实体 | AI 协助（默认） | 手工（收敛） | 说明与红线 |
| --- | --- | --- | --- |
| pft_test（肺功能检查登记） | 对话「登记这次肺功能」→ 候选（日期/设备/支气管舒张剂/报告文档）→ 核对接受 | 「⋯更多 → 登记检查」≤6 字段，日期键盘 | 一次检查的数值仍走 observation；报告原文不改写 |

| med_record 剂量变更 | 对话「改了剂量」→ 候选变更行 → 核对接受 | 「⋯更多 → 加变更行」≤6 字段 | 更正只新增版本（decision_version），不覆盖旧行 |
| imaging_study（影像登记） | 交报告 PDF → 解析候选 → 核对接受 | 「⋯更多 → 登记检查」≤6 字段 | HRCT 描述原文摘录，不判读 |

| visit_encounter / question_item（复诊待办） | 对话「整理这次要问的」→ 候选问题清单 → 核对接受 | 「⋯更多 → 新增问题」≤6 字段 | 勾选 asked 0/1；打印文本生成 |
| document / candidate（资料导入） | 交 PDF → 解析候选 → 核对接受/拒收 | 「⋯更多 → 手动登记」≤6 字段 | 拒收候选零副作用；原件永远保留 |
| oxygen_therapy（氧疗登记） | 对话「我在用氧」→ 候选氧疗记录 → 核对接受 | 「⋯更多 → 登记氧疗」≤6 字段 | in_use 状态切换；处方原文不改写 |

红线行：营养**不做热量换算/肌少症判定**；**不做 AI 生成**肺功能判定（PPF 属医生任务）；**不 AI 估算** mMRC/King-ILD 档位（用户自录原值）；移植评估**不输出资格结论**。
