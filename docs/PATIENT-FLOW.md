# PATIENT-FLOW · 小呼宝 BreathPal（草案 v0.1 · 未签认）

> 依据 ZERO-TO-DEV §1.1：一次真实就诊 / 一次日常记录 / 一次复查，各画一条「患者在什么时刻最难受 → 打开哪一页 → 得到什么产物」。**页面树由这三条反推，不从医生流程照搬。**
> ⚠️ 0 访谈声明：以下三条流程均为**代理推断 + 二手材料**（见 `research/USER-RESEARCH-2026-10-25.md` 证据分层），句中标注的"患者视角需要"全部是**改写句，非一手引语**。G1 签认前不构成已确认业务。

## 流程一 · 一次常规复诊前（3 个月节奏）

| 时刻 | 患者在什么 | 打开哪一页 | 得到什么产物 |
| --- | --- | --- | --- |
| 复诊前 1 周 | 家里堆着上次的肺功能报告和日常记的血压计/血氧值，不知道医生会问什么 | `复诊准备与问题清单` | 可勾选的"这次要问的" + 自动生成打印文本 |
| 复诊前 1 天 | 想知道自己这半年到底在掉还是稳 | `肺功能趋势`（一图秀首图） | FVC%pred / DLCO%pred 双序列 + 每次变化值（中性对照，无判读） |
| 候诊时 | 症状说不清："是这周突然变差还是这个月慢慢变差" | `氧状态与日常快记` | mMRC + SpO2 分段列表，能指出变化起点 |
| 诊室里 | 医生问"什么时候减的药" | `用药与耐受记录` | 按药聚合的剂量变更时间线（原样文本，不分级） |
| 诊室后 | 医生说了一句"可以考虑转诊评估"，没听懂 | `复诊准备与问题清单` 追加 | 把没听懂的记成"下次要问"，不生成诊断解释结论 |

患者视角需要（改写句，非一手）：
- 「我只想知道跟上次比是好了还是差了，别给我看一堆单子的数字。」→ 肺功能趋势
- 「复查前我希望能把要问的话列出来，不然进诊室全忘了。」→ 复诊准备

## 流程二 · 一次日常记录（气促变化周）

触发：感冒后爬三层楼就喘 → `氧状态与日常快记` 记一笔（mMRC 等级、静息/活动 SpO2、氧流量、自由文本）→ 连续 3 天后回看，变化起点在时间线上可指认 → 若"活动后 SpO2 掉到 88%"这类**用户自录值**出现，页面只做"该值已记录，复诊时可与医生讨论"中性回显（不写"危险/就医"判读——硬约束 22）。

## 流程三 · 一次急性加重住院（事件串联）

触发：急诊/住院 → `急性加重事件` 建事件卡（日期、诱因原文、出院带药、氧疗处方、复查节点）→ 事件在总时间线上成为独立锚点 → 出院后趋势页把事件前后两段并列展示（不合并、不算斜率结论）→ 32 号折叠卡：收起态一眼看到"何时/多久/带药"，展开态看明细。

医生任务 ≠ 患者需要（一票否决护栏）：PF-ILD/PPF 判定、急性加重诊断、移植适应证评估，均为医生任务；本仓只做**信息准备与并列口径展示**（`移植评估信息自检` 列"该带的检查与历史记录完整度"，不输出"你够/不够格"）。
