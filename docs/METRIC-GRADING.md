# METRIC-GRADING · 小呼宝 BreathPal（pf-ild-workbench）· v0.1

> 依据 23 号「分级与提醒」与 25 号「指南桥」。本癌种启用哪几项分级、为什么，逐条写。
> **核心原则：不做判读。分级只做「对照」，不写"偏高/偏低/严重"，不推断因果、不给处置。**

## 一、启用分级（逐项 + 理由 + 边界）

| 分级 | 适用指标 | 启用理由 | 边界（不做什么） |
| --- | --- | --- | --- |
| 绝对值对照 | FVC%pred / DLCO%pred / FEV1 / 6MWT / SpO2 | 患者最常被问「跟上次比怎么样」，绝对值对照是可核对的 | 不给"偏高/偏低/达标"，只并列展示；不插补缺失点（NULL ≠ 0） |
| 相邻变化对照 | 相邻两次肺功能差值 | 回答"半年内是掉还是稳" | 缺一侧（缺测）不生成差值；显示「缺一侧，无法计算」 |
| ×ULN 型（肝酶等安全性化验） | 用**该化验单自带 ref_high** | 防拿成人通用上限凑倍数 | 缺 ref_high → 返回 `needsUln`，不生成倍数 |
| 趋势斜率（展示） | FVC%pred 年变化率 | 移植评估需带历史，展示斜率是信息准备 | 不算"符合/不符合进展"结论（医生任务） |
| 分类量表 | mMRC / King's ILD / UCSD SBD | 患者日常自录功能与症状 | 只存用户自录原值，不存服务端计算档位；不进趋势折线 |

## 二、不启用分级（及理由）

| 分级 | 不启用理由 |
| --- | --- |
| 风险分层/预后（如"低危/中危/高危"） | 医生任务，一票否决；本仓不做判读 |
| 剂量调整建议（如"该减量"） | 处置建议，红线禁止 |
| 诊断分级（如"确定/疑似"） | 诊断属医生任务 |
| 感染/副作用严重度分级 | 处置建议，且需医学审核；改为原样文本记录 + 「该值已记录，复诊可与医生讨论」中性回显 |

## 三、提醒策略（Aler）

- 提醒只做**事实提示 + 时间窗**：「距上次肺功能检查已超过 3 个月」＝ 事实陈述，非建议。
- 不做："指标异常请就医"、"可能复发"等推断句。
- 阈值提示走「中性对照位」：页面只显示"该值已记录"，不写"危险/就医"。

## 四、×ULN 专项（25 号联动）

- 所有肝功能化验项必须带 `ref_high` 列；缺值时读模型返回 `needsUln`。
- 数值 `> ref_high` 时，只展示「已记录；复诊时可与医生讨论」，不生成倍数、不标"异常"。
- 空值先挡 `null/undefined/''` 再 `Number()`，防 `Number(null)===0` 把"没填上限"变成"上限 0"。

## 五、评审挂钩

- G3 闸口：判读列断言脚本检查 `diagnosis|risk_level|severity|stage|prognos` 列名，命中即 fail。
- V1 闸口：`npm run check` 检查分级文案红线。
- 独立评审一票否决：若设计/实现出现"给患者看的诊断或预后结论"，直接判 fail。
