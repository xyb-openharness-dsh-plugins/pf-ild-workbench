# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：PF-ILD 患者本人为主、家属辅助记录；中老年慢病程，跨病因表型（CTD-ILD/纤维化性HP/特发性等）

场景：肺功能（FVC%pred/DLCO%pred）半年一次的趋势判断；气促与氧状态的日常快记；抗纤维化药物耐受与剂量变更；急性加重住院前后的信息串联；移植评估时点的信息准备与复诊问题清单

核心流程：
1. 录入肺功能报告关键值，查看FVC/DLCO趋势走向
2. 日常快记气促等级、SpO2与氧流量
3. 记录抗纤维化药物剂量变更与耐受事件
4. 登记急性加重住院事件并串联前后趋势
5. 生成复诊问题清单与移植评估信息自检档案

完成结果：得到来源可追溯的个人纤维化病程档案：肺功能与氧状态趋势、急性加重事件卡、用药耐受记录、复诊准备材料；所有信息经用户核对入档，不提供诊断与治疗建议

初始布局选择：business-first
