## 推导轴（10 条疾病轴 × PF-ILD 差异）

| 轴 | PF-ILD 特有事实 |
| --- | --- |
| A1 分型 | PF-ILD 是**进展表型**定义，不是病理诊断；CTD-ILD / 纤维化型 HP / 职业性 / 特发性等病因混杂，患者最易把"进展"误读成肿瘤学语义 |
| A2 器官 | 肺单一器官；核心后果是**不可逆的功能下降**（FVC/DLCO）与缺氧，无手术截除 |
| A3 分期 | **无 TNM/FIGO**；"进展（PPF）"是功能描述，判定口径属医生任务 |
| A4 治疗 | 抗纤维化药（尼达尼布/吡非尼酮）+ 激素/免疫抑制 + 氧疗 + 移植（极少数）；无手术/放化疗主线 |
| A5 症状 | 劳力性气促（mMRC）、缺氧、乏力；急性加重是自然病程事件 |
| A6 营养 | 气促→进食减少、体重下降（呼吸性恶病质）；26 号 L6 体重部分适用 |
| A7 心理 | 慢病长期不确定、焦虑抑郁高发、照护者负担 |
| A8 随访 | 肺功能约 3 个月、HRCT 按需、6MWT、氧疗再评估 |
| A9 事件 | 急性加重（AE）住院事件——患者最需要知道"前后怎么变"的锚点 |
| A10 资源 | 尼达尼布等费用、医保（门诊慢特病/双通道/慈善赠药）、异地就医、肺移植评估（中国移植中心集中） |
