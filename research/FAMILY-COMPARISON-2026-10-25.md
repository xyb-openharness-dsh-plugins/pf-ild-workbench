## 二、26 号口径摘要 + R2 形态不适用逐条

### 2.1 乳腺癌（26 号口径）功能线摘要

出处 `docs/26-CANCER-FEATURE-LINES.md` §2（`:45-56`）+ §3（`:68-79`）。家族十条候选线 L1–L10：

| 线 | 名称 | 回答的患者原话 | 家族共通度 |
|---|---|---|---|
| L1 | 看板 / 首页 | 我现在整体什么情况？ | 必上 |
| L2 | 疾病本体线 | 我这个病到底处在哪一步？ | 必上（癌种拆法不同） |
| L3 | 治疗与决策线 | 我做过什么、接下来还有什么路？ | 必上 |
| L4 | 指标分析线 | 这个数高了/低了要紧吗？比上次呢？ | 必上 |
| L5 | 安全与症状线 | 这个不舒服是不是治疗带来的？ | 必上 |
| L6 | 营养与体重线 | 我吃得下吗？掉了的体重要紧吗？ | 强烈建议 |
| L7 | 心理与家庭线 | 我很怕，能跟谁说？家里人要做什么？ | 强烈建议 |
| L8 | 复诊与随访线 | 下次什么时候、带什么去？ | 必上 |
| L9 | 资料与导出线 | 我能不能整理好拿去给医生看？ | 必上（M5 可延后解析） |
| L10 | 试验与线索线 | 还有没有我能参加的研究？ | 按癌种（无真实登记库不设入口） |

三条固定贯穿机制（`:58-62`）：**① 指标分级层**（CTCAE v5.0 阈值表，只对有绝对阈值的项分级）；**② 一图秀/时间轴层**（多指标 + 事件同轴，独立归一化，单点不连线）；**③ 指南出处与节奏层**（四把刻度尺，处置推荐不进产品）。

结构阈值（`:33-37`）：一级 8–10 条、二级 24–30 条；一级 < 8 或二级 < 20 判结构性不足；判据（`:111`）：**任意两个癌种并排看，一级名称一致率 > 70% 且二级顺序一致 → 说明没做本癌种场景调研**。

乳腺癌实际落位（`docs/SPEC.md:58-67` + `public/js/pages-basic.js:10-28`）：看板 = L1；病情整理 = L2+L4+L9 的档案/指标/导入管线；病情一图秀 = ②时间轴；临床 = L3+L10 的二级「试验线索」；营养支持 = L6；心理支持 = L7；全程与康复 = L5+L8 的术后/上肢康复；收藏与回顾 = L8 的问题清单 + L9 的导出。

### 2.2 PF-ILD（R2 慢性病）天然不适用的口径（逐条）

| # | 26 号口径条目 | 不适用原因 | 出处依据 |
|---|---|---|---|
| 1 | **分期 / 分型档案**（TNM / FIGO / BI-RADS 分级） | R2 慢性病无分期体系；PF-ILD 只有 PFT 历史值与纤维化程度描述，不判分期 | 26号 L2；`cervical SPEC.md:55`、`breast SPEC.md:82` |
| 2 | **肿瘤标志物趋势与分级**（CA 系列 / SCC-Ag） | PF-ILD 无对应肿瘤标志物；26 号原文「标志物不做分级」 | 26号 L4（`:50`） |
| 3 | **手术 / 放疗 / 化疗治疗路径线** | 本病种无手术、放疗、化疗主线；主线是抗纤维化药 + 激素 + 免疫抑制的剂量与耐受 | 26号 L3；`cervical SPEC.md:35`、`breast SPEC.md:63` |
| 4 | **CTCAE v5.0 毒性分级阈值**（指标分级层） | CTCAE 是抗肿瘤治疗毒性分级；PF-ILD 用药无对应绝对阈值，改为原样文本、不分级 | 26号 §2 机制①（`:60`）；`docs/23-METRIC-GRADING-AND-ALERTS.md` |
| 5 | **预后 / 复发 / 进展风险分层** | 26 号与乳腺 SPEC 均明写不做复发风险预测；PF-ILD 的 PPF/急性加重判定是医生任务 | 26号 L2/L4；`breast SPEC.md:62` |
| 6 | **术后恢复与上肢淋巴水肿**（L5/L8 手术相关康复） | 无手术即无术后康复线；PF-ILD 的呼吸康复形态不同 | `breast SPEC.md:66,85` |

## 三、一级重名率实测（PF-ILD 候选 10 项 × 全部已提取一级名称）

**打分规则（与 CML 调研同款，可复算）**：字面同名 = 1，同域近义 = 0.5，无关 = 0；每条取全部仓中的**最高**分。命中池 = §一 全部已提取一级名（cervical 12 + breast 8 + cml 7/12）。

| # | PF-ILD 候选一级线 | 最佳对应（仓:一级名） | 分 | 逐条判定理由 |
|---|---|---|---|---|
| 1 | 肺功能趋势 | cerv「检查与指标」/ brst「病情整理」(二级·指标检测) | 0.5 | 同属 26 号 L4 指标分析域；家族一级无同名，「趋势」在家族里是 病情一图秀 / 指标检测 的能力，非独立一级名 |
| 2 | 氧状态与日常快记 | cerv「检查与指标」/ brst「病情整理」(二级·指标检测) | 0.5 | SpO2 属指标域；「日常快记」在家族落在二级「当下困扰 / 我的记录」，一级无同名 |
| 3 | 急性加重事件 | cerv「放疗与长期影响」/ brst「全程与康复」 | 0.5 | 同属 L5 安全与症状/事件记录域；病因不同（自然病程 vs 治疗远期），命名不同，按近义 |
| 4 | 用药与耐受记录 | cerv「治疗历程」/ brst「临床」 | 0.5 | 同属 L3 治疗线；家族把用药作治疗历程的子集，一级无同名 |

| 6 | 复诊准备与问题清单 | cerv「复诊准备」 | **1.0** | **字面同名**（含「复诊准备」） |
| 7 | 移植评估信息自检 | 无 | 0 | 家族（肿瘤工作台）无移植维度，属 PF-ILD 差异化空位 |
| 8 | 诊断追溯（起病到确诊时间线） | cerv「我的分期」/ brst「临床→病理·分子档案」 | 0.5 | 同属 L2 疾病本体档案域；PF-ILD 无分期，用病程时间线承接 |
| 9 | 资料与报告 | cerv/brst「病情整理」/ cml「资料夹、资料导入」 | 0.5 | 同属 L9 资料与导出域；「资料」为通用词，一级名不同，按近义 |
| 10 | 设置 | cerv「设置」(弹窗) / brst「设置」(弹窗) / cml「设置」 | **1.0** | **字面同名**（但两基准中为顶栏弹窗，非侧栏一级页；cml 亦为通用项） |

### 计算

- Σ匹配分 = 0.5×7（#1,2,3,4,5,8,9）+ 1.0×2（#6,10）+ 0×1（#7）= 3.5 + 2 + 0 = **5.5**
- PF-ILD 候选一级条数 = **10**
- **一级重名率 = 5.5 / 10 = 55.0%**

### 敏感性（口径摆动验证）

| 口径 | 处理 | Σ | 重名率 |
|---|---|---|---|
| 主口径 | 同名 1 / 近义 0.5 | 5.5/10 | **55.0%** |
| 从严 | 把 #1 肺功能趋势、#2 氧状态、#8 诊断追溯按「域不完全对等」降为 0 | 4.0/10 | 40.0% |
| 从宽 | #9 资料与报告按「L9 同域 + 含『资料』字面」升为 1 | 6.0/10 | 60.0% |
| 剔除通用项 | 只算 #1–#8（去掉 #9 资料与报告、#10 设置） | 4.5/8 | 56.25% |

### 判据结论

**55.0% ≤ 70%，家族判据合格**；从严/从宽/剔通用项三口径区间 **40.0%–60.0%（剔除通用项 56.25%）**，上限仍 ≤70%，结论对口径选择稳健。PF-ILD 的差异化主要由 #7 移植评估信息自检（家族空位）+ #1 肺功能趋势 / #2 氧状态 / #8 诊断追溯（R2 形态升格）撑起。

| 设置 | **字面同名（通用项）** | cerv / brst / cml「设置」 | **建议不设一级页**，沿用顶栏弹窗（与两基准一致），从一级候选剔除 → 一级数降至 9 |
| 资料与报告 | 近义 | cerv/brst「病情整理」、cml「资料夹/资料导入」 | 建议改为「报告与资料整理」或并入「检查与指标」的二级（资料导入），避免与家族管线域近义重叠 |

| 肺功能趋势 / 氧状态 / 急性加重 / 用药与耐受 / 影像档案 | 同域非同名 | 检查与指标 / 放疗与长期影响 / 治疗历程 | 保留——形态正当升格，非换名复用 |

> 即使不改名，重名率 55.0% 也已 ≤70%；改名的价值在于**降低 audit 的"换名复用"怀疑**，而非满足判据。

## 五、刻意不同（≥3 条，理由 + audit 风险）

1. **不设分期页**：PF-ILD 无 TNM / FIGO / BI-RADS 分期概念，分期档案页会空转。理由：R2 慢性病形态。
   **audit 风险：中**。26 号 L2「疾病本体线 = 必上」；若 audit 机械套用 L2，会判"缺疾病本体线"。**缓解**：在 DIFF-MATRIX §一 显式写「L2 不上，由『诊断追溯 + 肺功能趋势』承接疾病本体」——26 号 §8 明写"数量是走查下限，不是目标"，且要求"写下来才算决定过"。
2. **治疗线改为「用药与耐受记录」**：不设化疗线 / 放疗线，改为抗纤维化药 + 激素 + 免疫抑制剂的剂量变更与耐受事件记录。理由：患者最关心「什么时候减的药、为什么」。
   **audit 风险：中**。26 号 L3「治疗与决策线 = 必上」；但 L3 的家族样板是手术/放化疗路径，PF-ILD 无此主线。**缓解**：写明「L3 以用药耐受承接，手术/放化疗子项明确不做」。
3. **事件类型不同**：肿瘤仓是治疗事件（手术/放化疗/换药），本仓是**急性加重住院事件**（自然病程事件）。理由：急性加重是患者最需要知道"前后怎么变"的锚点。
   **audit 风险：低–中**。与 cerv「放疗与长期影响」、brst「全程与康复→不适记录」同域不同因；需在场景里给出「患者原话 / 页面接住 / 明确不做什么」三段式，避免被判空壳。
4. **新增「移植评估信息自检」**：肿瘤仓无移植。理由：肺移植是 PF-ILD 的关键窗口决策，信息自检（完整度清单）是纯记录不判资格。
   **audit 风险：低（加分项）**。家族空位，属正当差异化。
5. **趋势图是「肺功能趋势」而非「指标趋势」**：FVC%pred / DLCO%pred 为核心，量表（mMRC / King-ILD）分类不进趋势折线（只画点不连线）。
   **audit 风险：低**。但配套的**指标分级层（CTCAE）不适用**，必须在 §二 写明，否则 audit 会拿 CTCAE 阈值表来套 PF-ILD 指标卡。
